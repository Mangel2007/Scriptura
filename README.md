# Scriptura

Aplicación orientada a las frases motivacionales, que van desde frases bíblicas hasta estoicas.

## Prerrequisitos

- Kotlin

## Instalación

Clona el repositorio y entra en la carpeta del proyecto:

```bash
git clone https://github.com/Mangel2007/Scriptura.git
cd Scriptura
```
